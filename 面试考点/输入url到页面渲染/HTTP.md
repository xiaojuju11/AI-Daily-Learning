# HTTP/2.0
- 1.1的问题 
100 * n * RTT 
(100 * n * RTT) / 6 
带宽利用率低

100M - 12.5M

- 带宽利用率低：
1. 同时启用多条 TCP 连接，这写连接相互竞争带宽
2. TCP 的慢启动： 新建立的 TCP 连接，发送数据前，会先进行慢启动， 以避免对网络的拥塞
3. 队头阻塞问题： 当一个 TCP 连接中，某个请求的响应延迟了， 其他请求的响应也会被阻塞

- 解决队头阻塞问题：
1. 只保留一个 TCP 连接， 其他请求都在这个连接上发送
2. 将该TCP 连接中的多个请求切片：每个请求片段还可以打上加急标签， 服务器可以根据标签，优先处理加急的请求
3. 头部压缩： 对请求头和响应头进行压缩， 减少了数据的传输量

# HTTPS === HTTP + SSL/TLS
- TLS 是一种加密协议， 用来保护 HTTP 通信的安全

- 对称加密：客户端和服务端都知道一个密钥， 用这个密钥加密数据， 也用这个密钥解密数据。

- 非对称加密：客户端创建一个密钥，服务端创建一个公钥和一个私钥，服务端将公钥发送给客户端，客户端用公钥加密 密钥，传输给服务端，服务端用私钥解密密钥。
