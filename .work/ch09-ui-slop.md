# 第 9 章 AI 做的界面，为什么总差一点

> 不难看，是**没有决策**。而决策可以写成规则。

## 为什么需要它

让 AI"做一个好看的落地页"，你大概会得到：紫蓝渐变、居中大标题、三张卡片、圆角按钮、轻微阴影。

单看每个元素都挑不出错，合在一起就是"见过一百次"。

这种产出有个名字：**AI Slop**——精致但没有主张的东西。

## 术语表

| 术语 | 人话 | 类比 |
| --- | --- | --- |
| Slop | 精致但无主张的产出 | 酒店大堂的装饰画 |
| 设计 token | 颜色、字号、间距的固定档位 | 装修的材料清单 |
| 主张 | 这个页面最想让人记住的一件事 | 一句话电梯陈述 |

## 为什么会 Slop

模型是在海量网页上训练的。当你不给任何约束，只说"做一个好看的页面"，它的最优策略是**取训练数据里出现频率最高的那套组合**：最常见的字体、最保险的配色、最流行的布局。

频次最高的东西，必然是最没特点的东西——因为它被最多人用过。

所以问题不是"它审美差"，是**你在让它对平均数负责**。平均数不丑，只是不表达任何东西。

## 三个能真正改变结果的决策

### 一、每页只留一个主张

先回答问题：**这个页面最想让人做的一件事是什么？**

如果是"注册试用"，那大标题、按钮、留白全部为它服务，其他元素一律降级或删掉——AI 默认把所有信息平铺，因为它不知道哪个重要。

```text
这个页面只有一个目标：让人点"免费试用"。
其他内容（功能列表、案例、FAQ）都只能是次要信息，
视觉权重不能超过那个按钮。
```

### 二、先定 token，再让它画

"配色高级一点"是形容词，它只能猜。给具体档位，它就有约束：

```text
设计 token（不许新增）：
- 背景：#FAFAF8，卡片：#FFFFFF
- 文字：#1A1A1A（主）、#6B6B6B（次）
- 主色只有一个：#C2410C，只用于主按钮和当前选中态
- 字号：12 / 14 / 16 / 24 / 40，不许出现 18、20、32
- 圆角：8（卡片）、999（标签）
```

约束越具体，Slop 越少。**没有发挥空间的地方，它就不会去取平均值。**

### 三、给参考，别给形容词

"要克制""要高级""要有呼吸感"，这三个词它能给你一百种理解。

```text
参考 Linear 的定价页：大量留白，只有一处强调色，文字不用纯黑。
不要照抄布局，只学它的克制程度。
```

参考物是一个坐标系，形容词不是。

## 用 skill 管 UI 质量

前三条解决"这一页"，这一条解决"每一页"。

做法是把 UI 的验收标准做成可复用的技能，而不是每次靠嘴说。比如 `impeccable` 这套技能包，直接把动作拆成了命令：

| 命令 | 干什么 |
| --- | --- |
| `/audit` | 跨可访问性、性能、主题一致性的技术体检 |
| `/critique` | 从 UX 角度评：层级、信息密度、引导 |
| `/polish` | 最后一轮：对齐、间距、一致性 |
| `/typeset` | 字体、字阶、行高、字重 |
| `/layout` | 网格、留白、视觉节奏 |
| `/distill` | 砍掉多余复杂度 |
| `/document` | 生成 DESIGN.md，把视觉系统固化下来 |

关键是最后一条：**把设计系统写成文件**（`DESIGN.md` 或设计 token 文件），然后写进 `AGENTS.md`：

```markdown
## UI 规范
- 主色只有一个，只用于主按钮和选中态
- 字号只用 12/14/16/24/40 五档
- 新增页面先读 DESIGN.md，不许引入新的颜色变量
```

规则一旦写下来，就变成每次都会被检查的东西，不再依赖你当面描述。

## 翻车现场

::: warning 做了七版，每版都"还行"
提需求："做一个数据分析的落地页，要专业一点。"

七版之后，你把七张截图并排放在一起，发现它们是同一个页面的七个变体：同一个渐变、同一套卡片、同一个居中标题，区别只有颜色深浅。

问题在于每一轮你给的都是形容词（"更专业""更简洁"），形容词只能让它在平均数附近微调，永远跳不出去。

第八版换了个说法："参考 Stripe 的开发者文档首页，学它怎么用留白和等宽字体制造技术感。主色只用一处。" 这一版不一样了。
:::

## 自测三问

1. 你上一次说"好看一点"，具体想改的是什么？如果说不出来，是不是本来就没想清楚？
2. 你的项目有设计 token 吗？如果没有，哪些地方正在各自为政？
3. "参考某个具体页面"和"参考某种风格"，产出差别为什么那么大？
