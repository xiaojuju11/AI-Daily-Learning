# 项目运行说明

## 依赖分析

| 模块 | 是否需要安装 | 说明 |
|------|-------------|------|
| `torch` | ✅ 需要安装 | PyTorch 深度学习框架 |
| `torch.nn` | ✅ 随 torch 一起安装 | PyTorch 的子模块 |
| `torch.nn.functional` | ✅ 随 torch 一起安装 | PyTorch 的子模块 |
| `math` | ❌ 无需安装 | Python 内置标准库 |

**只需安装一个包：`torch`（PyTorch）**

---

## 安装命令

**CPU 版本**（无 GPU 也能运行）：
```bash
pip install torch
```

**GPU 版本**（如果有 NVIDIA 显卡，训练更快）：
```bash
# 根据你的 CUDA 版本选择，以下示例为 CUDA 12.6
pip install torch --index-url https://download.pytorch.org/whl/cu126
```

---

## 安装后验证

```bash
python -c "import torch; print(torch.__version__)"
```

输出类似 `2.7.1` 就表示安装成功。

---

> 💡 **建议**：如果只是学习这个 mini_transformer，装 CPU 版本就够了（约 200MB）。GPU 版本需要先安装 NVIDIA 显卡驱动和 CUDA Toolkit。
