## M2 · 基础层（无界面，可独立验证）

### - [x] T03 · 常量与工具层（§0 §3）

- **依赖**：T01
- **触及**：`js/app.js`
- **做什么**：存储键与枚举常量；`genId()`；`startOfDay()`；`getTimeStatus(dueAt, now)` 四档判定；日期格式化（手写，不用 `toLocaleDateString`）；字符串安全处理。建立 `window.CT` 命名空间对外暴露，作为调试与验收的可调用入口。
- **完成标准**：Console 中直接调用 `CT.Utils.getTimeStatus()` 逐档验证：昨天 → `overdue`；今天 23:59（当前上午）→ `today`；+2 天 → `soon`；+10 天 → `normal`；空值 → `none`。
- **验收对照**：AC-04（逻辑部分）

### - [x] T04 · 存储层（§2）

- **依赖**：T03
- **触及**：`js/app.js`
- **做什么**：`load()` / `save()` / `backupCorrupt()`；写入与读取全部包 `try/catch`；读取失败时把损坏原文备份到 `campusTasks:v1:corrupt` 再以空列表启动。
- **完成标准**：
  1. 调用 `CT.Store.save()` 后，DevTools → Application → localStorage 出现 `campusTasks:v1` 且 JSON 结构正确。
  2. 手工把该键改成 `{{{坏数据`，刷新页面 → 出现中文提示、页面不崩、`campusTasks:v1:corrupt` 中留有原文。
- **验收对照**：AC-14（数据安全部分）、AC-09（能力就绪，端到端验证在 T19）

### - [x] T05 · 领域层（§4）

- **依赖**：T04
- **触及**：`js/app.js`
- **做什么**：`addTask` / `updateTask` / `removeTask` / `toggleDone` / `moveStatus` / `visibleTasks` / `sortTasks` / `computeStats`。**纯函数优先**，不碰 DOM。
- **完成标准**：Console 逐函数验证——`sortTasks()` 对乱序输入返回 `dueAt` 升序且 `null` 排最后；`computeStats()` 对已知数据集返回正确的待办/今日/逾期/本周完成四个数。
- **验收对照**：AC-05、AC-11（逻辑部分）

## M3 · 列表视图（主流程跑通）

### - [x] T06 · 列表渲染与时间状态

- **依赖**：T02、T05
- **触及**：`js/app.js`
- **做什么**：`renderAll()` 骨架 + `renderList()`；每条任务渲染标题、课程、类型、优先级、时间标签与状态样式；渲染层严格只读 state。
- **完成标准**：注入已知数据集后，DOM 顺序为 `dueAt` 升序且无期限在最后；四档时间状态各自的**文字标签正确**，且**计算样式互不相同**（断言 `getComputedStyle`，不断言 `element.style`）。
- **验收对照**：AC-04、AC-05

### - [x] T07 · 新建任务

- **依赖**：T06
- **触及**：`js/app.js`
- **做什么**：表单弹窗打开/关闭/重置；标题必填校验与中文错误提示；保存后写入并重渲染。
- **完成标准**：填写后保存，任务出现在列表正确排序位置且 localStorage 已写入；标题留空提交 → 不产生新任务且出现中文提示。
- **验收对照**：AC-01、AC-02

### - [x] T08 · 完成与取消完成

- **依赖**：T07
- **触及**：`js/app.js`
- **做什么**：真实 `<input type="checkbox">` + `<label>`；切换 `status` 与 `completedAt`。
- **完成标准**：勾选后任务离开待办列表、`status==='done'`、`completedAt` 非空；取消勾选可完整恢复。
- **验收对照**：AC-03

### - [x] T09 · 编辑任务

- **依赖**：T07
- **触及**：`js/app.js`
- **做什么**：复用同一个表单弹窗，回填现有值；保存后 `id` 与 `createdAt` 不变。
- **完成标准**：改标题与截止时间后，列表位置随之更新，`id` / `createdAt` 保持不变。
- **验收对照**：FR-02

### - [x] T10 · 删除任务

- **依赖**：T07
- **触及**：`js/app.js`
- **做什么**：确认弹窗组件；确认后删除并重渲染。
- **完成标准**：点删除先出现中文确认弹窗，**此时数据未变**；确认后任务从列表与统计中消失；取消则毫无变化。
- **验收对照**：AC-12

### - [x] T11 · 概览统计

- **依赖**：T06
- **触及**：`js/app.js`
- **做什么**：`renderStats()` 渲染待办 / 今日到期 / 逾期 / 本周完成四个数字（全局口径，不受筛选影响）。
- **完成标准**：注入已知数据集，四个数字与实际逐项吻合；完成任务后「本周完成」+1。
- **验收对照**：AC-11

### - [x] T12 · 空状态与提示条

- **依赖**：T06

- **完成标准**：清空数据后显示中文引导而非空白页；调用提示条能显示中文消息且自动消失。
- **验收对照**：AC-13

## M5 · 筛选与数据

### - [x] T15 · 筛选与搜索

- **依赖**：T06、T13
- **触及**：`js/app.js`
- **做什么**：课程/类型/状态筛选 + 关键词搜索，统一经 `visibleTasks()` 在渲染前应用；状态筛选默认「未完成」，含全部/未完成/待办/进行中/已完成。
- **完成标准**：逐项设置筛选后可见卡片数等于期望值；关键词能匹配标题**与**备注；清空筛选即恢复全量。
- **验收对照**：AC-08

### - [x] T16 · 导入导出与异常处理

- **依赖**：T04、T05
- **触及**：`js/app.js`
- **做什么**：导出为 JSON 文件；导入经 `FileReader` + `try/catch` + 两档校验（结构错误整体拒绝，缺可选字段补默认值）；覆盖前弹窗确认。
- **完成标准**：
  1. 导出后清空再导入，数据与导出前**深度相等**（含 `id` 与完成状态）。
  2. 导入 `{坏JSON` 与 `{"tasks":"不是数组"}` → 均出现中文报错，且**原数据条数不变**。
- **验收对照**：AC-10、AC-14
