# 阶段 2：Structured Prompt

目标：展示把需求一次性、结构化地交给 AI 后，首版实现会更完整。请在**新的空目录 + 新 AI 会话**中，直接复制以下整段 Prompt。

## 完整 Prompt

```text
你是一名有丰富经验的前端工程师。

## 项目背景

我要开发一个面向大学生的校园任务管理 Web App，项目名称为 CampusTask。

这是一个课堂 Demo，希望项目结构简单，但功能完整、UI 有一定完成度。

## 技术要求

只允许使用：

- HTML
- CSS
- 原生 JavaScript
- localStorage

不允许使用：

- Vue
- React
- npm 第三方库
- 后端服务

项目必须能够直接通过浏览器运行。

## 核心功能

用户可以：

1. 创建任务
2. 编辑任务
3. 删除任务
4. 将任务标记为完成
5. 设置任务所属课程
6. 设置任务分类
7. 设置截止日期
8. 设置优先级：高 / 中 / 低
9. 按课程筛选任务
10. 按完成状态筛选任务
11. 查看全部任务

刷新浏览器后任务不能丢失，需要使用 localStorage 保存。

## UI 要求

整体风格：简洁、现代、类似现代效率工具。页面居中，使用卡片式设计，有明确视觉层级。

- 高、中、低优先级需要有明显区别。
- 已完成任务需要有明显状态变化。
- 空任务时需要显示 Empty State。
- 添加和编辑任务使用弹窗或抽屉。
- 界面需要在普通笔记本宽度下正常使用。

## 代码要求

代码拆分为：

- index.html
- styles.css
- app.js

不要把所有代码写进一个 HTML 文件。JavaScript 不要大量使用全局变量；任务数据结构保持统一，并使用清晰的函数划分。

## 验收标准

完成后我应该能够：

1. 创建一个“软件工程课程设计”任务，课程为“软件工程”，分类为“课程作业”，截止日期为未来某一天，优先级为“高”。
2. 刷新浏览器后，该任务依然存在。
3. 把它标记为完成，并看到明显的完成状态。
4. 按“软件工程”和“已完成”筛选，能找到该任务。
5. 编辑或删除该任务，列表和筛选结果能正确更新。

请先简要说明你的实现方案与文件结构；然后创建全部文件并实现功能。完成后自行检查上述验收标准，报告检查结果和如何运行。
```
