# coze和concurui的区别
coze:一个是一站式的AI应用智能体的开发平台扣子,它一站式的就是你可以在这个平台上面搭建工作流，也可以在这个平台上面直接发布成智能体

Conmfyui是专业的AI图像和视频生成工具，它就专搞跟图像和视频相关的，所以如果你想要去，比如说通过文案输入文案就能生成出来做电影的，那这个是首选，它精通于做视频这一块的节点.

如果你是新手、非技术人员，或想快速搭建通用 AI 应用 / 智能体，优先选择 Coze，它能帮你以最低成本快速落地想法。
如果你是设计师、AI 绘画爱好者，需要对图像 / 视频生成进行专业级控制，ComfyUI 是更好的选择，它能满足你对细节和创意的极致追求。



# Flutter = 跨平台 + 高性能 + 统一 UI
Flutter 是谷歌推出的跨平台 UI 框架，用一套代码就能同时构建 iOS、Android、Web 等多端应用。它基于 Dart 语言，自带 Skia 渲染引擎，不依赖原生控件，所以性能和体验非常接近原生；同时 “一切皆 Widget” 的组件化设计，加上热重载功能，开发效率也很高，很适合快速构建跨平台产品
