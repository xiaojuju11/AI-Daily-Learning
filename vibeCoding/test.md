# 面试官：你平时是怎么用AI写代码的？
- 我平时主要用codex + deepseek 来写代码

- 一般动手前我有一些自己的习惯性操作：
 1. 需求文档的制定：我可能需要跟AI交流很久，不断地调整我想要的需求功能，让AI辅助给我优化建议，给出初版的需求文档。

 2. 在制定需求文档的过程中，我会 /branch 一个新分支，我喜欢让AI去github上做搜索，做竞品分析，结合一些starts数高的项目，分析他们的功能和实现。有什么可参考的优点。最后整合一份需求文档。这份需求文档中，我好就做好核心功能的 P0 - PN 开发排序

 3. 打造Agents.md 契约文件：这个我踩过坑，早期我喜欢在Agents.md里面写几百条规则xxxxx，看了openai的文档，他们的团队也干过这种操作，也出了问题，后来openai 给出了一份标准建议，这个文件是一个活的文件，应该要目录式（渐进式披露）。xxxxxxx, 我的习惯是，定期xxxx


4. 我习惯性会在模型上下文来到50% 左右，就会压缩上下文，我会让Agnet 将上下文 落档到 HANDOFF.md 文件中。xxxxx
