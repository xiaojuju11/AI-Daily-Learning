# UI = f (state)
`UI = state` 是 React 声明式编程的核心思想，意思是UI是状态的纯函数映射。

我们开发的核心工作就是**管理状态**：先清晰定义组件的UI结构，确定在任意状态下页面应该渲染成什么样子；再梳理用户交互等行为，明确哪些操作会触发状态更新，以及对应的更新逻辑。

当state发生变化时，React会通过diff算法，自动、最小化地更新页面视图，不需要我们手动操作DOM。

# 虚拟Dom
虚拟DOM是描述UI的JS对象，用来解决原生DOM操作性能昂贵的问题。
当状态变化时，React会在内存生成新虚拟DOM，通过diff算法对比新旧虚拟DOM，找到最小改动，批量一次性更新真实DOM，减少重排重绘。
同时它带来声明式开发，降低DOM操作复杂度；并且不依赖渲染环境，支撑React跨平台能力。
