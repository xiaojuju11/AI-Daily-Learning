# JavaScript 精讲

> 讲清语言机制，再用手写实现验证理解，最后收口到 TypeScript。

## 这本书讲什么

从"能写"到"能解释"的那一层。每个机制都回答三个问题：

1. **它在规范里怎么定义**——不是背结论，是知道去哪查。
2. **它在运行时发生了什么**——调用栈、堆、执行上下文里到底多了什么。
3. **我怎么证明自己懂了**——手写一个最小实现。

## 适合谁

- 写过项目，但被问到"闭包为什么会内存泄漏"就卡住的
- 想系统过一遍前端面试高频机制的
- 已经在用 TypeScript，但说不清 `any` 和 `unknown` 区别的

## 章节路线

```
1 执行上下文与作用域 → 2 闭包与内存 → 3 this 与调用方式
→ 4 原型链与继承 → 5 异步与事件循环 → 6 手写系列 → 7 TS 类型体操
```

## 写作约定

- 每章开头一句话说清解决什么问题，结尾三问自测。
- 代码块写预期输出，读的人不跑也能对答案。
- 比喻只用一次，讲完立刻回到术语。
