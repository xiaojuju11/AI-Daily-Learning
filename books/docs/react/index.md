# React 深度进阶

> 不使用"React 是声明式的"这类复读句，直接看 Fiber、Hooks 链表和渲染调度。

## 这本书讲什么

- **Hooks 为什么会踩闭包陷阱**——从链表存储讲起，而不是背 `useRef` 偏方。
- **组件什么时候重渲染**——state 变了为什么有时不更新，memo 为什么有时没用。
- **工程化收口**——路由、状态管理、TS 类型推导怎么配合，才不会越写越乱。

## 章节路线

```
1 渲染与提交两阶段 → 2 Hooks 链表与闭包陷阱 → 3 状态管理选型
→ 4 性能优化实战 → 5 React Router 与数据加载 → 6 复杂交互（Flow / 动画 / 图表）
```

## 写作约定

- 讲原理必配一个"能复现问题"的最小组件。
- 每个优化手段都标出它换掉了什么成本。
- 结论后面跟一句"什么时候不要这么做"。
