# 第一个数学模型  N-gram
NNLM  &  N-gram

N-gram: 要预测一个词，只往前看 N-1 个词。  Bigram(N=2)

* 我今天去银行___
* 我昨天在支付宝买了一只股票，今天去银行___  Bigram(N=3)


- N-gram 只能看到紧挨着的词，一旦前面的上下文超出了窗口，就失忆

- N = 10  算力爆炸 、 数据稀疏0

- N很小，上下文不够， N 太大，见过的搭配就需要非常多，否则概率为0


# 神经网络语言模型 （NNLM、 Word2Vec）
- 平滑策略：
  1. 加一平滑：不管这个词有没有出现过，都认为它出现过一次
  2. 回退：先查N=3 ，如果不存在，再查N=2 ，如果不存在，再查N=1
  3. 插值：把N=3 、 N=2 、 N=1 的概率加权混在一起

# 向量（词向量）
- 将每一个词处理成一个向量，相似的词向量靠近，模型就不再语料库中查找“这个词出现过几次”，而是在向量空间中查找相似的表达

- Word2Vec 将这套方法发扬光大

- 从此模型就可以处理它在训练时没见过的词组


- 词向量是怎么训练出来的？
  Word2Vec 思路：CBOW(找周围词来预测中间词) & Skip-gram(找中间词来预测周围词)

  1. CBOW：我__咖啡  喝出现的概率很大，炫这种罕见词不太敏感
  2. Skip-gram：__喝__  (对低频词捕捉会更友好)

- ELMo (预训练模型)
    词向量不是固定的，要根据上下文动态调整

    解决了多义词的问题，但是依旧存在两个短板
    1. 采用的编码器LSTM，编码能力有限
    2. 把双向LSTM的结果直接拼接，方式比较粗暴

- POENAI把LSTM替换成立Transformer做了GPT (单向，只看上文)   ----适合生成文本
- Google做了BERT (双向，看上下文)   ----适合理解文本
- 两个模型都用Transformer结构，但是参数不同，所以性能不同

# Transformer 模型 起源：注意力机制
LSTM是一个序列模型，只能往前看，不能往后看
1. 无法并行 ----哪怕GPU再强，也发挥不出来
2. 长距离信息丢失 ----信息过长，无法记住所有的信息


LSTM(顺序处理) =》LSTM +(注意力) =》纯注意力/Transformer(彻底推翻)

- Transformer 核心：
  1. 编码器（Encoder）：读懂输入
  2. 解码器（Decoder）：生成输出
  3. 注意力机制（Self-Attention）：关注输入序列中的每个词，而不是只看当前词


- 大语言模型到底是怎么一个字一个字往外蹦的？
 1. 预填充：你输入的是“法国的首都是”，模型吃进去整个句子，所有词的注意力层同时计算，相当于把你说的话读懂
 2. 解码：模型在最后的注意力层，得到每个词的预测概率，从中选中下一个词“巴黎”。每一步都根据上一步的预测，来生成当前词的预测。---自回归


 ## 选择下一个词
 1. 温度：控制模型的创造力，低温-》概率分布更尖锐，模型倾向于更加安全的词，输出更保守，高温-》概率分布更平滑，模型倾向于更加随机的词，输出更开放
 2. Top-k: 只考虑概率最高的前k个词，其他词的概率都设为0，模型只考虑这k个词
 3. Top-p: 只考虑概率累计和大于等于p的词，其他词的概率都设为0，模型只考虑这p个词
 4. 重复惩罚：对重复出现的词，概率减小，防止模型重复输出
 5. 束搜索：不止保留一个最优词，而是保留多个词，从多个词中选择最优的

 - 关键的优化：KV缓存，将已经生成的哪些词的key和value，都缓存起来，每次只计算新值，避免重复计算

 Transformer == 编码器 + 解码器 + 注意力机制

 - 注意力机制核心：
 输入：“法国”“的”“首”“都”“是”
        |    |   |   |  |
      查询条

  Q：查询向量     我要找什么？    你手里的查询条
  K：键向量       我是什么？      书架上的标签
  V：值向量       我的实际内容？   书架上的书

  - 第一步：计算点击词的概率
  是.Q * 法国.K ->0.9
  是.Q * 的.K ->0.1
  是.Q * 首.K ->0.3
  是.Q * 都.K ->0.4
  是.Q * 是.K ->0.2

  - 第二部：softmax归一化成权重
  法国：0.9 - > 0.42
  的：0.1 - > 0.08
  首：0.3 - > 0.18
  都：0.4 - > 0.24
  是：0.2 - > 0.08

  - 第三步：按权重加权求和
  输出：0.42*法国.V + 0.08*的.V + 0.18*首.V + 0.24*都.V + 0.08*是.V

  注意力机制是使用计算出来的权重高的词“法国”“首”来预测下一个词，忽略“的”这种权重低的词。
