# 写作规格（WRITING.md）

这份文件规定了「小橘书房」里每一章长什么样。素材可以乱，成书不能乱——所有章节都按这个骨架写。

## 零、最高原则：信息无损

**素材里的具体信息，一条都不许丢。** 这条优先级高于所有风格要求。

具体指这些：

| 类型 | 例子 | 处理方式 |
| --- | --- | --- |
| 命令 | `/compact`、`/context`、`pnpm typecheck` | 原样写进正文 |
| 数字 | 「150～200 条指令」 | 原样保留，不模糊成「有一堆」 |
| 工具名 | Playwright、agent-browser、grill-me | 写全名，不写成「一些工具」 |
| 提示词 | 素材里给的 prompt | 保留结构和关键句，可补场景 |
| 清单 | 四项闸门、六条质检标准 | 逐条保留，可加解释但不能减条 |
| 完整规格 | 一个平台的实现要求 | 整段保留成「可以照着做」的样子 |

**允许做的加工只有三种**：补背景、补解释、补例子。
**禁止做的**：合并条目、抽象化描述、用比喻替换操作步骤、"大意如此"。

判断标准一句话：**读者能不能照着这一章做出来。** 能，就合格；只能"感受"到，就是没写完。

## 一、素材怎么给我

最省事的一句话：

> 素材在 `D:\AIforstudy\python\01-basics`，整理进书里

我需要的只有：

| 素材 | 必需 | 我拿它干什么 |
| --- | --- | --- |
| 该目录的 `README.md` | 最好有 | 判断你学到哪、当时想解决什么问题 |
| 代码文件（`.py`） | 有就够 | 挑能用的例子，改写成教学示例 |
| 报错截图 / 文字 | 可选 | 变成「常见坑」小节 |
| 你的一句话总结 | 可选 | 变成章首的「一句话结论」 |

**不用整理、不用排版、不用删注释。** 乱的原稿更适合我判断你的真实理解程度。

## 二、每章固定骨架（面向 0 基础）

一章 = 一个能独立读懂的主题，长度按信息量定，不设上限。顺序不能变：

### 1. 一句话结论

章首第一段，回答「这一章学完我能干什么」，不超过两行。

### 2. 为什么需要它

先说**没有它会怎样**，再说它解决了什么。必须是具体场景，不能是「这是重要特性」。

### 3. 术语先翻译成人话

凡是第一次出现的术语，先给一张三列表：术语 / 人话 / 类比。

比喻**只用一次**，用完立刻回到术语。不要一章里换三个比喻。

### 4. 具体怎么做（主体，占全章一半以上）

这一节是干货区，按素材的组织方式展开，**每个操作都给到能照做的粒度**：

- 命令写全，含参数；
- 提示词给完整版，不是「让它压缩一下」这种概括；
- 清单逐条列，每条一行，能打勾；
- 有数字的给数字。

### 5. 如果写错了会怎样

至少一个真实翻车现场：现象 + 原因 + 怎么改。

### 6. 和 JavaScript 对照（可选）

有可比性就给小表，没有就跳过。

### 7. 自测三问

覆盖：**概念**（说不说得清）、**判断**（给个场景问结论）、**动手**（做一件小事）。

### 8. 下一步

一句「下一章讲什么、为什么现在讲」。

## 三、语言约定

- 每段不超过 4 行，长段落拆开；
- 不用「显然」「众所周知」「简单来说」；
- 术语第一次出现写「中文（English）」，之后只用中文；
- 代码里的变量名用有意义的英文，不用 `a`、`b`、`foo`；
- 中文和英文、数字之间加空格。

## 四、质量红线

1. **不编造**：没学过的内容不写。
2. **不写不能跑的代码**：示例我都会实际执行一遍，贴真实输出。
3. **不堆术语**：一个概念讲完再进下一个。
4. **不许空洞**：「性能更好」「更优雅」这类话，要么给数字，要么删掉。
5. **不许丢信息**：见第零节。写完要对着素材逐条核对，缺一条就补。

## 五、我处理一章的流程

```
1. 读素材，列出「具体信息清单」（命令/数字/工具/提示词/清单）
2. 判断归属：哪本书、哪一章、要不要插新章
3. 写：按骨架，先落地干货，再补解释
4. 核对：清单上的每一条，在正文里找得到对应句子
5. 验：示例代码真的跑一遍
6. 构建 + 提交推送
```

第 4 步是新增的硬门槛。**清单上有一条没落地，这一章不算写完。**

## 六、一章的验收清单

- [ ] 章首两行内说清学完能干什么
- [ ] 有「没有它会怎样」的具体场景
- [ ] 术语有翻译表，比喻只用一次
- [ ] **素材里的命令、数字、工具名、提示词、清单，全部落地**
- [ ] 主体部分占一半以上，且能照着做
- [ ] 至少一个真实翻车现场
- [ ] 自测三问覆盖概念 / 判断 / 动手
- [ ] 全章没有一个「显然」
