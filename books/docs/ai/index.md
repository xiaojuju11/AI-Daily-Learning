# AI 应用工程

> 从调通一个接口，到做出能上线的 Agent —— 中间那些没人写进文档的坑。

## 这本书讲什么

- **LLM 应用的基本形状**：流式输出、结构化输出、Function Calling 三步闭环。
- **Agent 循环**：ReAct 为什么能跑通，工具调度和上下文工程怎么设计。
- **MCP 协议**：为什么需要它，和直接写函数调用的区别在哪。
- **RAG 与 Agentic RAG**：检索什么时候有用、什么时候纯属浪费 token。

## 章节路线

```
1 模型与接口 → 2 提示词与结构化输出 → 3 工具调用 → 4 Agent 循环
→ 5 MCP → 6 向量检索 → 7 RAG 与 Agentic RAG → 8 评估与成本
```

## 写作约定

- 不绑定某一家的服务商，换 provider 只改 `.env`。
- 每个例子给预期输出，包括报错长什么样。
- 讲完一个能力，紧跟一句"生产里它会怎么坏"。
