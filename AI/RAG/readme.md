# RAG retrieval augmented generation
RAG是一种技术，旨在让大模型回答问题的时候可以提前先去向量数据库中查找到和当前这个问题最相似的话题，然后根据这些话题，来生成符合用户需求的回答。
生成式检索增强

- 让大模型回答最新的东西
1. 使用搜索引擎 （通用领域很好用）
2. 私域检索

- 超长上下文大模型的全文嵌入 
256K context ≈ 17万个汉字 在企业场景下，办公文档，可以使用超长上下文大模型的全文嵌入，来实现更复杂的检索任务。不需要RAG

- 对结构化，语义化的文件系统 结合目录搜索与文件提取 
也不需要RAG

- 以上三种方式都有局限性

# 经典RAG技术
一套体系，结合 信息检索 和 语言生成的人工智能机构，通过将知识内容的文本转换成向量，存放在专门的向量数据库中。让大模型能够根据用户的问题，从数据库中检索到最相关的向量，从而生成符合用户需求的回答。

1. 向量数据库
2. 向量检索

向量相似度(余弦距离，欧氏距离，点积等) 
[1, 2, 3, 4, 5] 
[1, 2, 8, 5, 3]

- 构建向量检索
1. embedding 模型 来将文本转换成向量
2. 向量数据库 来存储向量 (vector database)
