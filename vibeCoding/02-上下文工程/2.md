# 怎么管理你的上下文
claudeCode: /context
codex: /status

- 上下文窗口不是越大越好，而是越干净越好


- 上下文腐烂，解决方法：主动管理你的上下文

# Agent每一轮工作完成后，我们有6个选择可以做
1. /continue: 继续当前任务
 直接在当前任务的基础上继续工作，不改变任务的上下文，不做任何清理

2. /rewind: 回滚到某一轮工作
 从某一轮工作开始，重新开始当前任务，清理后续任务的上下文
 
3. /compact: 压缩上下文
 压缩当前任务的上下文，只保留必要的信息

  - 不要等autocompact，手动压缩上下文
  - 给compact 一个明确的方向:   /compact 保留xxxxxxxx
  - 把autocompact关掉

  - 用文件做交接：
    在 /compact 之前，让Agent将当前的状态落到文件上
    ```
    把当前的进展、待办事项、已知的坑写进 HANDOFF.md，要具体要我明天打开一个全新的会话，只读这个文件就能直接继续工作
    ```

    ### 一份好的HANDOFF.md 文件  ./HANDOFF.md
    /clear： 清理当前任务的上下文，新会话开始第一句： ”读一下 HANDOFF.md 文件，我要继续工作“

4. /clear: 清理上下文
 清理当前任务的上下文，会开一个全新的会话
  

5. /branch: 分支任务
 分支当前任务，创建一个新的任务，新的任务基于当前任务的上下文

6. subagent: 让主会话创建子会话
 创建一个新的子任务，子会话会有独立的上下文，只负责返回结果给主会话
