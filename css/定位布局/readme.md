# 文档流
- html中的标签分为三类：
1. 块级元素（div）：默认占据一整行
2. 行内块元素（input,button）:可以同行展示，可以被设置宽高
3. 行内元素（a,span）:无法被设置宽高

- 浏览器在加载html时，默认从上往下，从左往右的排列这些元素
