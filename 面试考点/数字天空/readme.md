 # 浏览器的存储
  1. localStorage ：本地存储  内存大小大约 5-8M ，永久有效 (永久存储，除非手动删除，否则会一直存在)
  2. sessionStorage ： 会话存储 内存大小大约 5-8M ，（浏览器关闭后，数据会被清除）
  3. cookies ： 内存大小大约4K   （存储在浏览器端的键值对，每次请求都会携带在请求头中， 后端控制有效时间）
  4. IndexedDB ： 浏览器端的数据库，内存无穷大（取决于硬盘大小） ，（永久存储，除非手动删除，否则会一直存在）

# indexeDB 是什么？有什么用？
1. 客户端数据库 （存非常大的数据，结构复杂的数据）
2. 先打开数据库，在创建对象仓库（表），最后操作数据
