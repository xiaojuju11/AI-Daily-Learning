# 同源策略

  - 一个 url 的样子： https:   //192.168.1.31:   3000    /user/name?id=123
                     协议      域名              端口       路径   

  - 同源策略：协议、域名、端口必须相同 （旨在保护后端数据安全）


# 跨域解决方法
  1. jsonp: 借助 script标签的src不受同源策略限制的原理, 将请求放在src上发出，并给后端传递一个固定参数cb，在window上定义一个cb函数,当前端向后端发送请求时,后端接到请求时,会向前端响应数据,将数据作为cb函数的调用形式中的实参返回，导致window上的cb函数触发
    - 缺点：
      1. 只能发get请求
      2. 必须要后端配合

  2. cors: 后端配置响应头 Access-Control-Allow-Origin 的白名单，那么白名单中的域名就能跨域请求

  3. proxy: 代理服务器 
  前端向代理服务器发送请求, 代理服务器向后端发送请求, 后端返回数据给代理服务器, 代理服务器返回数据给前端

  4. nginx: 反向代理
  前端向nginx发送请求, nginx向后端发送请求, 后端返回数据给nginx, nginx返回数据给前端

  5. websocket: socket协议天生不受同源策略限制, 可以跨域请求

  6. postMessage: window.postMessage() 方法，可以实现不同窗口父子页面之间的跨域通信
