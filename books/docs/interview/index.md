# 面试与性能实战

> 不背八股，把每个高频题还原成"当时的瓶颈是什么，怎么量的，怎么解的"。

## 这本书讲什么

- **性能优化**：虚拟列表、大文件分片上传、并发调度、缓存策略——都从现象出发。
- **底层链路**：输入 URL 到首屏，每一步能卡在哪。
- **数据结构与设计模式**：只收真正在业务里用过的，不凑数。

## 章节路线

```
1 浏览器渲染流水线 → 2 万条数据渲染（虚拟列表 / 时间分片）
→ 3 大文件上传（切片 / 秒传 / 断点续传）→ 4 异步并发控制
→ 5 缓存与跨域 → 6 数据结构高频题 → 7 设计模式落地
```

## 写作约定

- 每道题先给"不优化会怎样"的实测数字。
- 方案要能跑，贴关键代码而不是伪代码。
- 最后写清取舍：这个方案在什么规模下会失效。
