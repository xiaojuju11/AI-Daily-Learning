# react
1. 一个 js 框架，提高 js 开发效率
2. JSX,让js 和 html 的交互变得更简便

# 单页应用的特点
1. 声明式UI
2. 组件化 （像搭积木一样开发整个项目）
3. 跨平台

# jsx
1. jsx == js + xml (html)
2. main .jsx是整个项目最外层的入口
3. jsx中只能放表达式不能放语句
4. 列表循环渲染
5. 条件渲染
6. 样式处理
